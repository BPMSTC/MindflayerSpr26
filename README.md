# Catmon - Choose Your Own Adventure Studio

A text-based choose your own adventure game with a feline twist. Built with Angular 21 and Bootstrap 5.

## Prerequisites

- [Node.js](https://nodejs.org/) (v22+)
- npm

## Setup

```bash
git clone <repository-url>
cd MindflayerSpr26/frontend
npm install
npm start
```

Open http://localhost:4200/ in your browser.

## Project Structure

```
frontend/
```
